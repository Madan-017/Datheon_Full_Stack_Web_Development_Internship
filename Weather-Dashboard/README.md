# 🌦️ Live Weather Telemetry Dashboard

A responsive and interactive weather dashboard that provides real-time weather information for cities around the world. Built using HTML, CSS, and JavaScript, with live weather data fetched from the OpenWeatherMap API.

## ✨ Features

- 🌍 **Global City Search** – Search for weather information in any supported city.
- 🌡️ **Live Temperature** – Display the current temperature and weather conditions.
- 💧 **Humidity Information** – View current humidity levels.
- 🌬️ **Wind Speed** – Display real-time wind speed.
- 🌡️ **Atmospheric Pressure** – View atmospheric pressure readings.
- 📅 **5-Day Forecast** – View upcoming weather forecasts.
- 🎨 **Dynamic Backgrounds** – Background colors change based on weather conditions and time.
- ⏳ **Loading Indicator** – Displays a loading animation while fetching data.
- ⚠️ **Error Handling** – Shows helpful messages for invalid cities or API errors.
- 📱 **Responsive Design** – Works on desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- OpenWeatherMap API
- Fetch API
- Async/Await

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Madan-017/Datheon_Full_Stack_Web_Development_Internship.git
```

### 2. Open the Project Folder

Navigate to `Task-3-Weather-Dashboard`.

### 3. Configure the API Key

1. Create an account at [OpenWeatherMap](https://openweathermap.org/).
2. Generate an API key.
3. Open `script.js`.
4. Add your API key to the API configuration.

**Important:** Never upload your private API key to a public GitHub repository. Use a secure configuration or backend proxy for production.

### 4. Run the Application

Open the project using VS Code and launch `index.html` with Live Server, or run a local HTTP server.
