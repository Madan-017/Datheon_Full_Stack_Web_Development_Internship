# ✨ TaskFlow – Productivity Task Manager

TaskFlow is a modern, colorful and responsive productivity application designed to help users organize daily tasks, manage priorities, and track their progress.

## 🚀 Features

- Create new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Categorize tasks into Work, Personal and Study
- Set due dates
- Filter tasks by All, Active and Completed
- Search tasks
- Drag-and-drop task reordering
- Dark and light theme toggle
- Automatic data saving with browser localStorage
- Responsive design for mobile, tablet and desktop
- Smooth animations and interactive UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- Browser localStorage API
- CSS Flexbox and Grid

## 💻 How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Madan-017/Datheon_Full_Stack_Web_Development_Internship/
   ```

2. Open the project folder in VS Code.

3. Start a local server:

   ```bash
   npx -y http-server . -p 8081
   ```

4. Open `http://127.0.0.1:8081` in your browser.

## 💾 Data Storage

TaskFlow uses the browser's localStorage API to save tasks and theme preferences. Tasks remain available after refreshing the browser on the same device and browser.

## 🌐 Deployment

The application can be deployed using Vercel, Netlify or GitHub Pages.
