
# Developer Portfolio Website

A modern, responsive developer portfolio built using HTML5,
CSS3 and JavaScript.

## Features

- Responsive mobile-first design
- Dark and light theme
- Interactive mobile navigation
- Smooth scrolling
- Skills showcase
- Featured project cards
- Project detail modal popups
- Resume download
- Contact and social links

## Technologies

- HTML5
- CSS3
- JavaScript ES6
- Git
- GitHub

## Folder Structure

developer-portfolio/
- index.html
- style.css
- script.js
- README.md
- assets/
  - profile.jpeg
  - resume.pdf

## Installation

1. Clone the repository.
2. Open the project folder in VS Code.
3. Add your profile picture and resume.
4. Open index.html using Live Server.

## Customization

Replace the sample name, email, education,
social links and project details with your own information.

## Deployment

Deployed using Vercel.
